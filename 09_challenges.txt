================================================================================
  CHALLENGE 3: Duplicate and modify
================================================================================

Take the function template below and create 5 versions of it,
each with a different name (add, subtract, multiply, divide, modulo).
Use  yy  to copy and  p  to paste, then  cw  to rename.

function_name(a, b):
    return a operation b

Delete only the lines that start with "JUNK:" and keep everything else.
(You'll need to use  dd  on each junk line, or search for JUNK with  /JUNK  then  dd  then  n  then  dd...)

  JUNK: garbage line one

================================================================================
  CHALLENGE 5: Multi-file task
================================================================================

This challenge spans multiple files. Open a vertical split and work in both.

  Step 1: Open  scratch.txt  in a vertical split:  :vsp scratch.txt
  Step 2: In scratch.txt, write a short poem (3 lines) in Insert mode
  Step 3: Switch to this window with  Ctrl+w h
  Step 4: Copy the first two lines of Challenge 1 above with  2yy
  Step 5: Switch to scratch.txt with  Ctrl+w l
  Step 6: Paste below the poem with  p
  Step 7: Save scratch.txt with  :w  and come back here

================================================================================
  CHALLENGE 6: Navigation speed run
================================================================================

Starting from the TOP of this file (press  gg  now), race to do this:

  1. Jump to the bottom with  G
  2. Jump back to the top with  gg
  3. Search for "CHALLENGE 3" with  /CHALLENGE 3  ENTER
  4. Jump to end of that line with  $
  5. Jump to the word "function_name" with  *  (while cursor is on it)
  6. Set a mark 'z' there with  mz
  7. Go to bottom of file with  G
  8. Jump back to the mark with  'z

================================================================================
  CHALLENGE 7: The :s power move
================================================================================

Replace ALL occurrences of "foo" with "bar" in this block,
then replace ALL occurrences of "baz" with "qux",
using a single :%s command for each.

  foo = foo + baz
  result = foo(baz, foo)
  if foo > baz:
      return foo - baz
  foo.baz = baz.foo
